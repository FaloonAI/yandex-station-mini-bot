# 🤖 Yandex Station Mini (YNDX-0004) Telegram Bot Control

Полностью автономный, легковесный сервис на **Go** для удаленного управления рутированной **Яндекс Станцией Mini 1** (`yandexstation-mini_lplay`, SoC Amlogic A113X, `aarch64`) через Telegram из любой точки мира — без компьютера, без ADB и без сторонних облаков.

---

## 🌟 Возможности

* 📱 **Интерактивное Inline-меню:**
  * Управление через команду `/start` с клавиатурой быстрых кнопок.
  * Плавное редактирование сообщений in-place (без спама в чат).
  * Навигационная кнопка **«⬅️ Назад»** на каждом шаге.
* 📊 **Паспорт системы (`/status` & Fastfetch):**
  * Запуск встроенного `fastfetch` прямо на колонке с выводом фирменного ASCII-логотипа, нагрузки 4 ядер Cortex-A53, RAM, аптайма и температуры.
  * Уровень сигнала Wi-Fi в реальном времени (SSID, RSSI в dBm, IP-адрес).
* 🎙️ **Двусторонняя рация (Интерком):**
  * Отправка любого голосового сообщения в Telegram — колонка мгновенно воспроизводит его через динамик в комнате.
  * Сразу после воспроизведения колонка включает микрофонный массив, записывает 5 секунд ответа из комнаты и отправляет аудиозапись обратно в Telegram.
* 👂 **Скрытая прослушка комнаты (`/listen [сек]`):**
  * Дистанционная запись звука с микрофонов (5, 10, 15, 30 сек) с конвертацией и отправкой голосового файла в чат.
* 📢 **Мемный саундборд (`/play <звук>`):**
  * Воспроизведение звуков (*Airhorn, Bruh, Discord, Fart, Metal Pipe, Rickroll, Siren, WinXP*) через штатный ALSA-тракт (`aplay`).
* 🔊 **Синтез речи (TTS) (`/say <текст>`):**
  * Любой отправленный текст или команда озвучиваются вслух на русском языке.
* 🎚️ **Управление громкостью:**
  * Регулировка уровня громкости (шагами ±10%, пресеты 20%..100%, переключатель `Mute/Unmute`) через `amixer`.
* 🚨 **Охранная сирена:**
  * Дистанционное включение/выключение сирены тревоги на максимальной громкости.
* 💬 **История диалогов с Алисой (`/dialogs`):**
  * Просмотр последних голосовых запросов и ответов из локальных логов колонки.
* ✋ **Управление датчиком жестов (ToF VL53L0):**
  * Блокировка/разблокировка оптического датчика верхнего сенсора одной кнопкой.
* 🔔 **Уведомление при включении (Boot Notification):**
  * Автоматическая отправка оповещения в Telegram, когда колонка включается в розетку и подключается к сети.
* ⚡ **Высокая эффективность:**
  * Бинарник весит всего **~6.3 МБ**, потребляет **~10–12 МБ RAM** и **0% CPU** в режиме ожидания.
  * Автозапуск при старте колонки через интеграцию со службой Alice Homebrew.

## ⚙️ Настройка и конфигурация

Создайте файл `config.json` (он уже добавлен в `.gitignore`):

```json
{
  "bot_token": "ВАШ_ТОКЕН_ОТ_BOTFATHER",
  "admin_id": 123456789,
  "sounds_dir": "/data/telegram-bot/sounds",
  "scripts_dir": "/data/telegram-bot/scripts",
  "log_path": "/data/telegram-bot/bot.log",
  "quasar_logs": "/data/quasar/daemons_logs/maind.log",
  "aplay_path": "/system/workdir/bin/aplay",
  "arecord_path": "/system/workdir/bin/arecord",
  "amixer_path": "/system/workdir/bin/amixer"
}
```

* `bot_token`: токен вашего бота от `@BotFather`.
* `admin_id`: ваш цифровой Telegram ID (от `@userinfobot`). Бот принимает команды **только от этого пользователя**.

## 🚀 Сборка и развертывание

### Кросс-компиляция для Linux ARM64:

```powershell
$env:GOOS = "linux"
$env:GOARCH = "arm64"
go build -ldflags="-s -w" -o bin/yandex-mini-bot ./cmd/bot
```

### Автоматическое развертывание на колонку:

Запустите скрипт развертывания через PowerShell:

```powershell
.\scripts\deploy.ps1
```

Скрипт автоматически:
1. Скомпилирует актуальную версию бинарника для `linux/arm64`.
2. Загрузит бинарник, звуки и скрипты в каталог `/bkupgrade/data/telegram-bot/` на колонке.
3. Пропишет хук автозапуска в `/data/alice-homebrew/start.sh`.
4. Запустит бота в фоне.
